# UI/UX: продолжение редизайна, 17 сентября 2026

Актуальная договорённость: работаем над десктопом. Мобильный этап и его приёмка отложены до отдельного указания пользователя.

## Сделано в этом проходе

- Календарь: понятные названия дат для диктора, фокус внутри разрешённого диапазона, клавиатура (стрелки, Home/End, Page Up/Down), запрет перехода в недоступный месяц и выбора недоступного «Сегодня». Убрана вложенная кнопка очистки внутри кнопки открытия. Проверяется корректность ISO-даты, время суток больше не блокирует максимальную дату. Попап удерживается в пределах доступной области.
- Конструктор вопросов: сворачиваемые карточки с формулировкой, типом и обязательностью. Предпросмотр использует тот же компонент ответов, что и настоящий опрос. Подписи шкалы редактируются отдельными полями: незаконченный ввод не исчезает. Выведены минимум/максимум вариантов множественного выбора; новый вопрос начинает с допустимого предела 2 из 2 вариантов.
- Списки: общий выбор сотрудников с серверным поиском и постраничной загрузкой. Применён в фильтре оценок и в мастере назначения. Выбор сохраняется при смене страниц, есть обзор выбранных и ограничение 50 человек. Устранено ограничение первыми 100 сотрудниками. Фильтр включает архивных сотрудников, мастер — только активных.
- Карточки участника: выделен следующий шаг, видны состояние, число вопросов, известное время и прогресс начатого опроса. Экран вопроса отделяет номер текущего вопроса от числа заполненных ответов.
- Сохранение: запросы выполняются последовательно с актуальной ревизией, быстрый повторный ввод не получает ложное «Сохранено» от предыдущего запроса. Переход к проверке и возврат к списку ждут успешного сохранения. Ошибка остаётся рядом с действием повтора, конфликт другой вкладки блокирует дальнейшее редактирование. Закрытие вкладки с несохранённым вводом вызывает предупреждение браузера.
- Числовой ответ: пустое поле не превращается в 0, границы и шаг объясняются рядом с полем. Множественный выбор не разрешает превышать заданный максимум и объясняет, как заменить вариант.
- Локальный `/design-preview`: интерактивный стенд настоящих компонентов с синтетическими примерами. Не обращается к API, ничего не записывает в БД, в production возвращает 404.

## Обратная связь по оставшейся работе

| Приоритет | Область | Что улучшить и зачем |
|---|---|---|
| Высокий | Редакторы методик | При конфликте версии не заменять пользовательский черновик серверной копией без возможности сохранить свой текст. Сейчас `resyncPending` может привести к потере локальных изменений. Нужен отдельный сценарий сравнения версий. |
| Высокий | Идентификаторы вопросов | Генераторы используют только текущий список; удаление последнего элемента и добавление нового может переиспользовать код. Нужен постоянный реестр выданных кодов или независимые идентификаторы, согласованные с ключами подсчёта. |
| Высокий | Приёмка закрытых экранов | Проверить настоящие сценарии руководителя, администратора и участника после входа. В текущем браузере доступна только форма входа; предпросмотр не заменяет проверку с API. |
| Средний | Рецензент | Сохранить одновременно видимыми вывод, выбранный источник и чек-лист; снизить число переходов между вкладками. Отдельно довести интерфейс запросов на исправление. |
| Средний | Заключение руководителя | Держать сначала краткий вывод и последствия для решения, затем основания и ограничения. Для длинных источников добавить раскрытие деталей с корректной печатной версией; оговорки не скрывать. |
| Средний | Списки | Развить сохранение фильтров и сортировки в URL, явные действия по пустому результату и различение ошибки от пустого списка. Проверить одинаковое поведение во всех каталогах. |
| Средний | Конструктор сценария | Предпросмотр всего маршрута участника, сводка обязательных/необязательных методик и общей нагрузки только по известным данным. |
| Отложено | Мобильная версия | Доработка и полная проверка после отдельного сигнала пользователя. |

## Проверки и границы

TypeScript web и ESLint web проходят. 76 unit-тестов проходят, включая 3 регрессии очереди сохранения: повторный ввод во время запроса, отказ/повтор, уход со страницы во время запроса.

В браузере проверены реальные компоненты на `/design-preview`: раскрытие конструктора, редактирование подписи шкалы, предпросмотр, ограничение выбора, очистка числового ввода клавиатурой, календарь и фокус на границе диапазона. Десктопный вид просмотрен визуально. Ранее начатая мобильная проверка остановлена по просьбе пользователя.

Новый полный сквозной прогон с авторизованными ролями и интеграционные тесты БД в этом проходе не выполнялись. Статусы Error на исходном скриншоте не использовались как доказательство отсутствия реализации: актуальное состояние определялось по коду и доступному интерфейсу.


## Второй десктопный проход: заключения и рецензент

- Единая карточка источника (`components/reports/evidence-card.tsx`) используется в опубликованном заключении и при рецензировании. В ней видны содержание, вид, дата, ограничение вида источника и отдельные ограничения самого свидетельства (последние ранее не выводились).
- Рецензент выбирает источник под утверждением; выбранное свидетельство открывается рядом с текстом в `EvidenceBrowser`. Панель источника, чек-листа и действий остаётся закреплённой на desktop. Чек-лист не отмечается автоматически.
- В черновик добавлены ранее отсутствовавшие блоки: последствия для решения, следующие шаги, условия пересмотра вывода. Явно обозначены черновик, номер ревизии и демонстрационный режим.
- Очередь проверки получила поиск по коду/сценарию, сортировку по дате, число найденных и сброс поиска. По умолчанию сначала дольше ожидающие черновики.
- В опубликованном заключении следующие шаги показывают адресата: руководитель, сотрудник, совместное обсуждение. При печати сетка заключения становится одноколоночной.
- Исправлен stateful RegExp в автопроверках: последовательные процентные формулировки больше не пропускаются. Проверка также включает последствия для решения и следующие шаги. Добавлены две регрессии.
- Проверено: web TypeScript, web ESLint, 78 unit-тестов. В браузере на десктопе проверен общий компонент переключения источников, текст ограничений и перевод фокуса. Предпросмотр синтетический и не заменяет проверку прав или настоящей публикации.
- **Не выполнено:** полный проход по закрытым страницам после входа и окончательная визуальная приёмка всех страниц. Вкладка стенда остаётся на `/login`; запрос на вход передан пользователю. Администратор и участник потребуют соответствующих демонстрационных доступов. Мобильная версия не дорабатывалась.
